setting up a github repository for the first time

when setting up a github a github repository for the first time you need to folowing steps

  • git inint
  • git add.
  • git commit -m"initial commit"
  • git branch -M main
  • git remote add origin

updating a git hub repository

when updating a git repository or pushing to an existing repository reuse the following steps

  1. git add.
  2. git commit -m"update commit"
  3. git push origin main
